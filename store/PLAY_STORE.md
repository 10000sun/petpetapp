## 1. 스토어 등록 정보 (초안)
- **앱 이름(30자)**: petpet - 쓰다듬기
- **간단한 설명(80자)**: 홈 화면의 앱 아이콘을 누르면 손이 쓰다듬어 주는 귀여운 효과 앱
- **자세한 설명**:
  petpet 모드를 켜고 홈 화면으로 가면, 앱 아이콘이나 위젯을 누를 때 앱이 실행되는 대신 손이 톡톡 쓰다듬어 줘요.
  • petpet 버튼 한 번으로 시작, done으로 종료
  • 스와이프(페이지 넘기기, 전체 앱 열기)는 그대로
  • 상단바 알림에서 실행 상태 확인, 누르면 앱으로 복귀
  ※ 홈 화면 위에 효과를 표시하기 위해 접근성 서비스 권한이 필요합니다. 읽은 정보는 기기 밖으로 전송되지 않습니다.
- **카테고리**: 도구(또는 엔터테인먼트) / **광고 포함**: 예
- **그래픽**: 앱 아이콘 `store/ic_launcher_512.png`, 피처 그래픽 `store/feature_graphic_1024x500.png`

## 2. 데이터 보안(Data safety) 양식
| 항목 | 답변 |
|---|---|
| 데이터 수집 여부 | 예 (광고 SDK) |
| 수집 데이터 | **기기 또는 기타 ID(광고 ID)**, 앱 활동/진단 정보(AdMob이 수집) — 목적: **광고 또는 마케팅**, 분석 |
| 개발자가 직접 수집/서버 전송 | 없음 (접근성으로 읽는 정보는 기기 내 처리, 저장·전송 없음) |
| 제3자와 공유 | 예 — Google AdMob (광고 목적) |
| 전송 중 암호화 | 예 |
| 데이터 삭제 요청 | 개발자 보관 데이터 없음 (광고 ID는 기기 설정에서 재설정) |
※ AdMob 가이드의 "SDK가 수집하는 데이터" 표를 보고 최종 확인하세요.

## 2-1. 인앱 결제·통계
- 앱 설명에 "앱 내 구매 포함(커피 한 잔 후원 = 광고 제거)" 표기 (스토어 정보의 "인앱 상품 포함" 자동 표시)
- 통계(쓰다듬은 앱 이름/횟수)는 기기 내 저장만 — 데이터 보안 양식에서 수집으로 체크하지 않음 (전송 없음)
- 빌링 라이브러리는 7.1.1. Play가 최신 버전 사용을 요구하면 올리기

## 3. 광고 관련 규칙 (정책 위반 방지)
- 광고는 **앱 메인 화면 하단**에만 표시 (홈 화면 오버레이, 알림, 다른 앱 위 금지)
- 접근성으로 얻은 정보를 광고에 사용하지 않음
- 광고와 petpet/done 버튼 사이 간격 유지 (실수 클릭 방지) — 현재 하단 60dp 영역
- 아동 대상 앱이 아님으로 설정 (대상 연령 13세 이상 권장 — 아동 대상이면 광고 제한이 크게 늘어남)
- 유럽경제지역(EEA) 동의: UMP 동의 양식이 자동 표시됨 (AdMob 콘솔 → 개인 정보 보호 및 메시지에서 양식 게시 필요)

## 4. 접근성 권한 선언(Permissions Declaration Form) 초안
- **핵심 기능**: 홈 화면에서 앱 아이콘/위젯 터치를 감지해 앱 실행 대신 애니메이션을 보여주는 것. 접근성 서비스 없이는 다른 앱(런처) 위 터치를 처리할 수 없음.
- **사용 기능**: 창 상태 변경 감지(런처가 앞에 있는지), 화면 노드 읽기(터치한 아이콘/위젯 영역 확인), 제스처 전달(스와이프를 런처에 그대로 전달)
- **수집/전송**: 없음. 기기 내 처리, 광고 미사용.
- **사용자 동의**: 앱 내 동의 팝업(접근성 설정 이동 전) 표시
- **시연 영상 시나리오**: ① 앱 실행 → 도움말 → petpet 누름 → 동의 팝업 → 접근성 설정에서 켜기 ② petpet 모드 시작, 홈에서 아이콘 탭 → 손 애니메이션, 앱 미실행 ③ 스와이프로 페이지 넘기기 ④ 상단바 알림 → 앱 복귀 → done
- **주의**: `isAccessibilityTool`은 장애인 보조 도구 전용이라 설정하지 않음. 심사에서 거절될 수 있으니 거절 사유를 보고 설명/영상을 보완.
- **사이드로드 설치본**: Android 13+에서는 스토어 외 설치 앱의 접근성 켜기가 "제한된 설정"으로 막힘 (앱 정보 → ⋮ → 제한된 설정 허용).

## 5. 기술 점검
- targetSdk/compileSdk 36, AGP 8.10.1 (Play의 최신 요구 수준은 콘솔에서 재확인)
- 아이콘: 적응형 + 모노크롬(`mipmap-anydpi`), 알림 아이콘은 흰색 단색(`ic_notification`)
- 릴리스 린트는 JDK 25 오류 때문에 비활성화. JDK 17/21로 Gradle을 돌리면 다시 켜도 됨
- 릴리스마다 `versionCode` 증가
